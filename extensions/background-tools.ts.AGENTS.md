# background-tools.ts — per-file record (sidecar)

Promoted from `extensions/AGENTS.md` (row exceeded the size threshold). Pull-only; search-indexed.

Handlers over the background registry, used only when `allowBackground` is on: `makeAgentMessagesTool` (`messagesPage`: default last 20, `from`/`next_from`, `kinds` filter before paging, emits `result_read via:"messages"` when entries returned), `makeAgentListTool` (`summaryOf` rows + counts line), `makeAgentCancelTool(registry, stopAgent)` (ids or `"all"` + `status` filter → per-id `stopped`/`already_finished`/`not_found`/`ambiguous`, stops via the shared `AgentControlRegistry.stop(agentId, "tool")`). Shared views `statusOf`, `summaryOf`, `messagesPage`, `countsLine` also feed the query channels. All text bounded by `resultMaxChars`. See change: add-background-subagents. Now the handler set behind `AgentControl` actions `list`/`messages`/`cancel` (factories no longer registered). Rows gain `run`, `turns`, `cwd`, `asking` (`askLineOf` short form); cancel `status: idle` + outcome `disposed` via `DisposeIdle`. See change: add-subagent-orchestration. `makeAgentStatusTool`/`readStatuses`/`waitFor`/`resolveStatus`/`DEFAULT_STATUS_WAIT_S` removed (status folded into `wait`). New `progressLine(record)` (id, status, type, run, turn, cwd, ask short form, activity, tokens, last-text tail ≤200 while running) shared by wait/steer/reply/cancel; `missLine(id, not_found|ambiguous|not_alive)`; cancel appends progress lines; `emitResultRead` via `wait|push|messages`; `AgentStatusDetails` kept `@deprecated`. See change: agent-control-unified-wait.
