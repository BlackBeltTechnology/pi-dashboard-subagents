# extensions/ — per-file record

Extension source for `@blackbelt-technology/pi-dashboard-subagents`. pi loads
the default export of `index.ts`. Foreground subagent spawning, plus background spawning when `allowBackground` is on (per-subagent stop via inbound `subagents:stop`); per-event
timeline streamed to the dashboard bridge via `pi.events.emit("subagents:*")`.

| File | Purpose |
|---|---|
| `agent.ts` | Agent tool registration + spawn loop + agent-`.md` resolution. Default export `activate(pi)` registers the `Agent` tool and a `resources_discover` handler. `resolveAgentMdPath(type, cwd, bundledDir?, packageIndex?)` resolves `.md` across FOUR tiers, first match wins: project → user → bundled → package; returns `{ path, source, pkg? }`; path-traversal guard (`/`, `\`, `..`) short-circuits first. Tier 4 = package discovery: `buildPackageAgentIndex(cwd, agentDir)` scans installed pi packages' `agents/*.md`. USER-SCOPE ONLY — project-scoped packages never indexed (deliberate conservative default, NOT an SDK limit; SDK does expose `ExtensionContext.isProjectTrusted()`/`SettingsManagerCreateOptions.projectTrusted`). De-dupes by `source`, skips `filtered`, sorts ascending by `source` for deterministic collision winner + stderr warn; NEVER throws (empty index on any failure). Module cache keyed by cwd via `refreshPackageAgentIndex` / `ensurePackageAgentIndex` (rebuild on cwd change or `resources_discover`). `parseAgentMd(path)` reads frontmatter (`model`/`tools`/`prompt`/`inherit_context`/`description`); undefined on missing/empty/malformed. `resolveModelFromRef(pi, ref, mdPath)` resolves `model:` via `model:resolve` event, falls back to `pi.modelRegistry`; `@role` needs a handler. `runAgentTool` runs an in-memory `SessionManager.inMemory(cwd)` subagent, strips `Agent` from tools, intersects frontmatter `tools:` allowlist. `BUNDLED_AGENTS_DIR`/`EXTENSION_ROOT` from `import.meta.url`. Spawn cost is bounded three ways (change: reduce-fanout-parent-stall): `createChildLoader(cwd)` builds a fresh lean `DefaultResourceLoader({cwd, agentDir, noSkills, noPromptTemplates, noThemes})` per child and passes it as `resourceLoader` — NEVER share a loader (one mutable `runtime` per loader; `bindCore` overwrites it, first `dispose()` poisons siblings); `createProgressEmitter(sink, windowMs)` takes a SINK plus a LAZY `schedule(() => details)` so coalesced events never call `buildDetails`, fanning one throttled stream out to `emitSubagentProgress` + `onUpdate`, with `pushTerminalUpdate` delivering terminal status synchronously; module-level FIFO semaphore (`acquireSpawnSlot`/`dispatchSpawnWaiters`, limit `getMaxConcurrent()`, `0` = unlimited) acquired AFTER `emitSubagentCreated` (card shows `queued`) and BEFORE loader/session, released in `finally`; abort while queued rejects with `SpawnAbortedError` → `aborted` result, no session, slot never consumed. `pi` handle bound PER-ACTIVATION via lexical closure: `activate(pi)` passes its own `pi` into `makeAgentTool(pi, exposeIsolated)`; module-level `pi` is FORBIDDEN — nested subagent sessions re-activate this same module instance and clobber the parent's handle, which their `dispose()` then invalidates (stale-ctx on 2nd `Agent` call). Child session: `createAgentSession({ modelRuntime, model, thinkingLevel })`. Model precedence: tool-call `model` > frontmatter `model:` > parent live `ctx.model` > SDK default (settings `defaultModel`); `model` key omitted when none. `getParentModelRuntime(ctx)` reads private `ctx.modelRegistry.runtime` (no public accessor), warns once + returns undefined when missing. Thinking levels incl. pi 1.x `max`. Thinking precedence: ref suffix (incl. `off`) > `ctx.thinkingLevel` > `pi.getThinkingLevel()` > pi defaults. Removed `modelRegistry`/`authStorage` options (dead since pi 0.80.8). `nextLiveTail(prev, event)` folds `thinking_*`/`text_*` deltas into a ≤ `LIVE_TAIL_MAX` (280) suffix; `_end`/`message_end` → `CLEARED_LIVE_TAIL`; `snapshotDetails` sends cleared tail on non-running snapshots. `activityFromEvent` keeps last activity on `tool_execution_end`. `snapshotDetails` sets `thinkingLevel` = live `session.thinkingLevel` ?? requested level. `appendEntry(entry)` in `runAgentTool` = ONLY timeline push site: push, then `emitSubagentEntry` once (sync, unthrottled, `index = entries.length-1`). `runAgentTool(..., pi, toolCallId = "")`; `execute` passes its tool call id. `createBlockDeltaEmitter(sink, windowMs)` = append-only accumulator for streaming block (pending APPENDED never replaced, ≤1 non-final piece/window trailing-edge, `open`/`close`/`dispose` emit `final:true` synchronously, implicit open on stray/kind-switched delta); `runAgentTool` closes block BEFORE `appendEntry(entry, blockId)` on `_end` + before `message_end` backfill, `dispose()` on every terminal path + `finally`. See change: stream-subagent-entries-per-step, stream-subagent-reasoning-and-stable-card, add-agent-md-frontmatter-and-bundled-explore, add-model-resolve-event-with-fallback, add-model-param-to-agent-tool, add-package-agent-discovery-tier, fix-stale-pi-handle-on-reactivation, fix-subagent-thinking-and-pi1-compat, emit-subagent-block-deltas, inherit-parent-live-model, harden-subagent-lifecycle. Outcome = final assistant `message_end` (`finalReplyFailure`: stopReason error/aborted or empty text → `failWith`); `throwIfAborted` after slot grant, `createChildLoader`, `createAgentSession`; child loader `extensionsOverride: stripChildSettlementHandlers` drops `turn_end`/`agent_end`/`agent_before_settle`/`agent_settled`; `boundToolResult(text, details, limits)` bounds tool result + terminal `onUpdate` only, bus events full. Per-subagent stop: `createAgentControlRegistry()` (per activation, NEVER module-level) → `register`/`stop(agentId)→`StopOutcome`/`size`; `activate` listens `subagents:stop {agentId}` (guards `pi.events.on` absent). `runAgentTool(..., toolCallId, controls?)` owns per-agent `AbortController` linked to parent (`{once}`, removed in `releaseControl`), `endReason` latch first-wins (`parent`→`failWith("aborted")`, `{stop}`→`stopWith(phase)`: `subagents:completed` `status:"stopped"`+`stopReason`, NO `isError`). Semaphore: waiter records `{start,onPosition}`, fair grant (immediate only when `spawnWaiters` empty), `schedulePositionPush` microtask-batched one frame per waiter via `pushQueuedFrame` → `onUpdate` ONLY (never bus: keeps bus volume O(runs), guarded by fanout-memory bound), `syncRecheckTimer` 1 s `unref`'d `setInterval(dispatchSpawnWaiters)` only while waiters exist; limit change re-pushes. Snapshots: `stoppable:true`; queued `queuePosition`/`activeSlots`/`maxConcurrent`; `slotGrantedAt` after grant; `startedAt` = creation. See change: manage-subagent-spawn-queue. Background subagents (change: add-background-subagents): `activate` creates a per-activation `BackgroundRegistry` when `isBackgroundAllowed()` (read once) and passes it to `makeAgentTool`; `buildAgentParametersSchema(exposeIsolated, allowBackground=false)` adds optional `run_in_background` + `timeout_s` only when on (property map built imperatively; `execute` casts params to `AgentToolArgs`). `spawnInBackground` checks `getMaxBackgroundPending()` (rejection = error result listing outstanding ids, no record/events), starts `runAgentTool` unawaited with NO parent signal and `RunAgentOptions { background: true, onAgentId, onEntry, onRunning }`, returns `details: BackgroundSpawnDetails` (`background: true`, `id`, `status`, `queuePosition?`, `counts`, never `agentId`). Spawn semaphore has lanes: `SpawnLane` on each waiter, `enqueueWaiter` inserts foreground waiters before the first background one (dispatch = `shift()`, index = queue position; a jump triggers the batched position push). `AgentControl.stop(by: StopSource)` / `registry.stop(agentId, by = "event")`; `stopWith` sets `details.stoppedBy`. `SUBAGENT_MANAGEMENT_TOOLS` (Agent + 4 background tools) stripped from children. `Agent.execute` runs `subagents:before_spawn` first (veto → error result with `SpawnVetoDetails`, nothing created). `runAgentTool` runs `subagents:before_store` via `storeText` on every terminal path (completed, failed, stopped) before emitting/bounding. `RunAgentOptions.timeoutMs` arms a run timer at slot grant (stop `"timeout"`), cleared in `releaseControl`; `backgroundId` feeds `before_store.id`. Background `activate` also registers the four background tools, a `session_shutdown` handler (stops outstanding background runs with `"shutdown"`), and `subagents:list` / `subagents:get` responders (fill `out` only when unset, own registry only, never mark read). Retries are observed, never driven (change: surface-subagent-retries): the subscribe closure handles `auto_retry_start` first (close block deltas, `appendEntry(retry)`, `retries += 1`, `lastRetrySequence = { attempts }`, activity `retrying (attempt N/M) in <delay>…`, liveTail cleared, `pushUpdate`) and `auto_retry_end` (records `success`, no entry). `snapshotDetails` carries `retries`. `withRetrySuffix(failure, seq)` adds ` (after 1 retry)` / ` (after N retries)` only when the final reply errored and the last sequence ended `success: false`; aborted/stopped paths untouched. Both retry branches also emit `subagents:retry` (`scheduled` on `auto_retry_start`, `ended` on `auto_retry_end`). |
| `events.ts` | Emission layer + timeline types + parent-context inheritance. Wire types `AgentDetails`, `SubagentTimelineEntry`, `AgentStatus`, `TokenUsage`. `AgentDetails.agentMdSource` is `"project"\|"user"\|"bundled"\|"package"`; `agentMdPkg?` carries the originating package `source` string when `source === "package"`. `buildDetails(snapshot)` builds an `AgentDetails` from running state. `emitSubagent{Created,Started,Progress,Completed,Failed}` fire `pi.events.emit("subagents:*")` (bridge renames to `subagent_*`). `emitSubagentProgress` OMITS `entries` key (thin tick). `emitSubagentEntry` fires `subagents:entry` `SubagentEntryEvent { v:1, agentId, toolCallId, index, entry }`. `buildDetails` sets `entryCount = entries.length`. `mapSessionEventToEntry` maps `_end`-flavored session events to entries (idempotent). `createToolCallTracker` pairs `tool_execution_start`→`end` to backfill input. `LiveTail` type + `CLEARED_LIVE_TAIL` sentinel; `buildDetails` always sets `liveTail` (defaults to sentinel). `buildInheritedContext(ctx, opts)` + `compressParentContext` produce the `<parent-context>` prefix (verbatim compaction, no LLM). `SubagentDeltaEvent { v:1, agentId, toolCallId, blockId, kind, offset, text, final }` + `emitSubagentDelta` fire `subagents:delta`; `SubagentEntryEvent.blockId?` links streamed-block steps. See change: scaffold-foreground-subagent-extension, add-agent-md-frontmatter-and-bundled-explore, add-package-agent-discovery-tier, fix-stale-pi-handle-on-reactivation, stream-subagent-entries-per-step, emit-subagent-block-deltas, harden-subagent-lifecycle. `AgentDetails.entriesOmitted?` set only on bounded tool result. Optional `stoppable`/`stopReason`/`queuePosition`/`activeSlots`/`maxConcurrent`/`slotGrantedAt`; `buildDetails` omits each key when unset. See change: manage-subagent-spawn-queue. `AgentDetails.background?: boolean` (set on every snapshot) and `stoppedBy?: "tool" | "event" | "timeout" | "shutdown"`; `buildDetails` passes both through only when set. See change: add-background-subagents. Retries (change: surface-subagent-retries): `SubagentTimelineEntry` kind `"retry"` `{ attempt, maxAttempts, delayMs, text, ts }`; `retryEntryFromEvent(event)` maps pi's `auto_retry_start` (defensive defaults: numbers → 0, empty message → `"Unknown error"`), `null` otherwise; `formatRetryDelay(ms)` (`4s`, `2m 30s`, `1h 5m`; sub-second → `1s`); `AgentDetails.retries?` passed through `buildDetails` only when > 0. `SubagentRetryEvent` (`phase: "scheduled"` with attempt/maxAttempts/delayMs/error, or `"ended"` with attempt/success/finalError?; both with `v`, `agentId`, `toolCallId`, running `retries`) and `emitSubagentRetry` on `subagents:retry`, unthrottled. |
