# extensions/ — per-file record

Extension source for `@blackbelt-technology/pi-dashboard-subagents`. pi loads
the default export of `index.ts`. Foreground-only subagent spawning; per-event
timeline streamed to the dashboard bridge via `pi.events.emit("subagents:*")`.

| File | Purpose |
|---|---|
| `agent.ts` | Agent tool registration + spawn loop + agent-`.md` resolution. Default export `activate(pi)` registers the `Agent` tool and a `resources_discover` handler. `resolveAgentMdPath(type, cwd, bundledDir?, packageIndex?)` resolves `.md` across FOUR tiers, first match wins: project → user → bundled → package; returns `{ path, source, pkg? }`; path-traversal guard (`/`, `\`, `..`) short-circuits first. Tier 4 = package discovery: `buildPackageAgentIndex(cwd, agentDir)` scans installed pi packages' `agents/*.md`. USER-SCOPE ONLY — project-scoped packages never indexed (deliberate conservative default, NOT an SDK limit; SDK does expose `ExtensionContext.isProjectTrusted()`/`SettingsManagerCreateOptions.projectTrusted`). De-dupes by `source`, skips `filtered`, sorts ascending by `source` for deterministic collision winner + stderr warn; NEVER throws (empty index on any failure). Module cache keyed by cwd via `refreshPackageAgentIndex` / `ensurePackageAgentIndex` (rebuild on cwd change or `resources_discover`). `parseAgentMd(path)` reads frontmatter (`model`/`tools`/`prompt`/`inherit_context`/`description`); undefined on missing/empty/malformed. `resolveModelFromRef(pi, ref, mdPath)` resolves `model:` via `model:resolve` event, falls back to `pi.modelRegistry`; `@role` needs a handler. `runAgentTool` runs an in-memory `SessionManager.inMemory(cwd)` subagent, strips `Agent` from tools, intersects frontmatter `tools:` allowlist. `BUNDLED_AGENTS_DIR`/`EXTENSION_ROOT` from `import.meta.url`. See change: add-agent-md-frontmatter-and-bundled-explore, add-model-resolve-event-with-fallback, add-model-param-to-agent-tool, add-package-agent-discovery-tier. |
| `events.ts` | Emission layer + timeline types + parent-context inheritance. Wire types `AgentDetails`, `SubagentTimelineEntry`, `AgentStatus`, `TokenUsage`. `AgentDetails.agentMdSource` is `"project"\|"user"\|"bundled"\|"package"`; `agentMdPkg?` carries the originating package `source` string when `source === "package"`. `buildDetails(snapshot)` builds an `AgentDetails` from running state. `emitSubagent{Created,Started,Progress,Completed,Failed}` fire `pi.events.emit("subagents:*")` (bridge renames to `subagent_*`). `mapSessionEventToEntry` maps `_end`-flavored session events to entries (idempotent). `createToolCallTracker` pairs `tool_execution_start`→`end` to backfill input. `buildInheritedContext(ctx, opts)` + `compressParentContext` produce the `<parent-context>` prefix (verbatim compaction, no LLM). See change: scaffold-foreground-subagent-extension, add-agent-md-frontmatter-and-bundled-explore, add-package-agent-discovery-tier. |
| `index.ts` | Extension entry point. `default export` re-exports `activate` from `agent.ts` (pi's loader uses the default export). Public re-export barrel for downstream consumers: settings, events, and agent-resolution symbols (`resolveAgentMdPath`, `PackageAgentIndex`, `buildPackageAgentIndex`, `refreshPackageAgentIndex`, `ensurePackageAgentIndex`, `parseAgentMd`, `resolveModelFromRef`, types). Imports many SDK/TUI symbols that are not all re-exported (pre-existing unused-import lint warnings). See change: scaffold-foreground-subagent-extension, add-package-agent-discovery-tier. |
| `settings.ts` | Extension config persistence at `~/.pi/agent/extensions/pi-dashboard-subagents/config.json`. Lazy in-memory cache, atomic tmp-file-rename writes, defaults baked in so missing file/fields never throw. `DashboardAgentSettings` = `{ inheritContext (default true), exposeInheritanceInTool (default false), inheritance: { recentTurns 6, toolOutputWindow 2, maxChars 24000 } }`. Getters: `shouldInheritByDefault`, `shouldExposeInheritanceInTool`, `resolveIsolated(perCall)` (per-call value honored only when `exposeInheritanceInTool` on), `getInheritanceCompression` (operator-only, never exposed to LLM). `loadSettings`/`saveSettings`/`invalidateSettingsCache`/`getSettingsPath`. See change: scaffold-foreground-subagent-extension. |
| `__tests__/agent.test.ts` | Vitest for `agent.ts` pure helpers: schema conditional `isolated`, `selectEffectiveModelRef`, `resolveAgentMdPath` tiers 1–3 + traversal guard, `createProgressEmitter` throttling, `createUsageAccumulator`, `parseAgentMd`. Mocks the SDK (`getAgentDir`→tmp, `parseFrontmatter`→tiny stub). |
| `__tests__/events.test.ts` | Vitest for `events.ts`: `mapSessionEventToEntry`, tracker pairing, emission channels, `compressParentContext`, `formatTokens`, `buildDetails`. |
| `__tests__/inheritance-e2e.test.ts` | Vitest end-to-end for context-inheritance compression path. |
| `__tests__/model-resolve.test.ts` | Vitest for `resolveModelFromRef`: `model:resolve` primary path + `pi.modelRegistry` fallback, `@role` hard-fail, error surfaces. |
| `__tests__/package-discovery.test.ts` | Vitest for tier-4 package discovery: index build, deterministic collision + warn, tier-4 resolution + higher-tier precedence, traversal-guard short-circuit, tolerant scan, undefined `installedPath` skip, construction/list throw → empty, user-scope-only, `filtered` skip, dual-scope de-dupe, empty default-seam, cwd-change rebuild. See change: add-package-agent-discovery-tier. |
| `__tests__/settings.test.ts` | Vitest for `settings.ts`: load/merge/save round-trip, defaults, cache invalidation, `resolveIsolated` matrix. |
