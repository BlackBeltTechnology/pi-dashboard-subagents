# extensions/ — per-file record

Extension source for `@blackbelt-technology/pi-dashboard-subagents`. pi loads
the default export of `index.ts`. Foreground-only subagent spawning; per-event
timeline streamed to the dashboard bridge via `pi.events.emit("subagents:*")`.

| File | Purpose |
|---|---|
| `agent.ts` | Agent tool registration + spawn loop + agent-`.md` resolution. Default export `activate(pi)` registers the `Agent` tool and a `resources_discover` handler. `resolveAgentMdPath(type, cwd, bundledDir?, packageIndex?)` resolves `.md` across FOUR tiers, first match wins: project → user → bundled → package; returns `{ path, source, pkg? }`; path-traversal guard (`/`, `\`, `..`) short-circuits first. Tier 4 = package discovery: `buildPackageAgentIndex(cwd, agentDir)` scans installed pi packages' `agents/*.md`. USER-SCOPE ONLY — project-scoped packages never indexed (deliberate conservative default, NOT an SDK limit; SDK does expose `ExtensionContext.isProjectTrusted()`/`SettingsManagerCreateOptions.projectTrusted`). De-dupes by `source`, skips `filtered`, sorts ascending by `source` for deterministic collision winner + stderr warn; NEVER throws (empty index on any failure). Module cache keyed by cwd via `refreshPackageAgentIndex` / `ensurePackageAgentIndex` (rebuild on cwd change or `resources_discover`). `parseAgentMd(path)` reads frontmatter (`model`/`tools`/`prompt`/`inherit_context`/`description`); undefined on missing/empty/malformed. `resolveModelFromRef(pi, ref, mdPath)` resolves `model:` via `model:resolve` event, falls back to `pi.modelRegistry`; `@role` needs a handler. `runAgentTool` runs an in-memory `SessionManager.inMemory(cwd)` subagent, strips `Agent` from tools, intersects frontmatter `tools:` allowlist. `BUNDLED_AGENTS_DIR`/`EXTENSION_ROOT` from `import.meta.url`. Spawn cost is bounded three ways (change: reduce-fanout-parent-stall): `createChildLoader(cwd)` builds a fresh lean `DefaultResourceLoader({cwd, agentDir, noSkills, noPromptTemplates, noThemes})` per child and passes it as `resourceLoader` — NEVER share a loader (one mutable `runtime` per loader; `bindCore` overwrites it, first `dispose()` poisons siblings); `createProgressEmitter(sink, windowMs)` takes a SINK plus a LAZY `schedule(() => details)` so coalesced events never call `buildDetails`, fanning one throttled stream out to `emitSubagentProgress` + `onUpdate`, with `pushTerminalUpdate` delivering terminal status synchronously; module-level FIFO semaphore (`acquireSpawnSlot`/`dispatchSpawnWaiters`, limit `getMaxConcurrent()`, `0` = unlimited) acquired AFTER `emitSubagentCreated` (card shows `queued`) and BEFORE loader/session, released in `finally`; abort while queued rejects with `SpawnAbortedError` → `aborted` result, no session, slot never consumed. `pi` handle bound PER-ACTIVATION via lexical closure: `activate(pi)` passes its own `pi` into `makeAgentTool(pi, exposeIsolated)`; module-level `pi` is FORBIDDEN — nested subagent sessions re-activate this same module instance and clobber the parent's handle, which their `dispose()` then invalidates (stale-ctx on 2nd `Agent` call). See change: add-agent-md-frontmatter-and-bundled-explore, add-model-resolve-event-with-fallback, add-model-param-to-agent-tool, add-package-agent-discovery-tier, fix-stale-pi-handle-on-reactivation. |
| `events.ts` | Emission layer + timeline types + parent-context inheritance. Wire types `AgentDetails`, `SubagentTimelineEntry`, `AgentStatus`, `TokenUsage`. `AgentDetails.agentMdSource` is `"project"\|"user"\|"bundled"\|"package"`; `agentMdPkg?` carries the originating package `source` string when `source === "package"`. `buildDetails(snapshot)` builds an `AgentDetails` from running state. `emitSubagent{Created,Started,Progress,Completed,Failed}` fire `pi.events.emit("subagents:*")` (bridge renames to `subagent_*`). `mapSessionEventToEntry` maps `_end`-flavored session events to entries (idempotent). `createToolCallTracker` pairs `tool_execution_start`→`end` to backfill input. `buildInheritedContext(ctx, opts)` + `compressParentContext` produce the `<parent-context>` prefix (verbatim compaction, no LLM). See change: scaffold-foreground-subagent-extension, add-agent-md-frontmatter-and-bundled-explore, add-package-agent-discovery-tier, fix-stale-pi-handle-on-reactivation. |
| `index.ts` | Extension entry point. `default export` re-exports `activate` from `agent.ts` (pi's loader uses the default export). Public re-export barrel for downstream consumers: settings, events, and agent-resolution symbols (`resolveAgentMdPath`, `PackageAgentIndex`, `buildPackageAgentIndex`, `refreshPackageAgentIndex`, `ensurePackageAgentIndex`, `parseAgentMd`, `resolveModelFromRef`, types). Imports many SDK/TUI symbols that are not all re-exported (pre-existing unused-import lint warnings). See change: scaffold-foreground-subagent-extension, add-package-agent-discovery-tier. |
| `settings.ts` | Extension config persistence at `~/.pi/agent/extensions/pi-dashboard-subagents/config.json`. Lazy in-memory cache, atomic tmp-file-rename writes, defaults baked in so missing file/fields never throw. `DashboardAgentSettings` = `{ inheritContext (default true), exposeInheritanceInTool (default false), maxConcurrent (default 4, 0 = unlimited), inheritance: { recentTurns 6, toolOutputWindow 2, maxChars 24000 } }`. `maxConcurrent` coerces non-number/non-finite/negative to default, floors fractions. Getters: `shouldInheritByDefault`, `shouldExposeInheritanceInTool`, `resolveIsolated(perCall)` (per-call value honored only when `exposeInheritanceInTool` on), `getInheritanceCompression` (operator-only, never exposed to LLM). `getMaxConcurrent()` re-checks the config file mtime and invalidates the cache on change, so operators retune the spawn cap without `/reload`. `loadSettings`/`saveSettings`/`invalidateSettingsCache`/`getSettingsPath`. See change: scaffold-foreground-subagent-extension, reduce-fanout-parent-stall. |
| `__tests__/agent.test.ts` | Vitest for `agent.ts` pure helpers: schema conditional `isolated`, `selectEffectiveModelRef`, `resolveAgentMdPath` tiers 1–3 + traversal guard, `createProgressEmitter` throttling, `createUsageAccumulator`, `parseAgentMd`. Also covers activation-handle isolation: two `activate()` calls with distinct fake handles — each tool emits through its OWN handle, and invalidating the later handle does not break the earlier tool. Plus a source-scan guard: reads `agent.ts` and asserts no module-scoped `: ExtensionAPI` declaration and no `getPi()` accessor (fails closed — both regexes match the pre-fix source). Plus a `runAgentTool` spawn-path suite: per-spawn lean loader identity/options/`reload` count, failing `reload` → error result, coalesced `onUpdate` burst (≤ 2 calls, `buildDetails` spied via a partial `../events.js` mock), terminal `completed`/`error`/`aborted` `onUpdate`, cap FIFO order + `queued` cards, cap 0, abort-while-queued, slot release on every terminal path. Mocks the SDK (`getAgentDir`→tmp, `parseFrontmatter`→tiny stub, `DefaultResourceLoader`→recording class via `vi.hoisted`). See change: fix-stale-pi-handle-on-reactivation, reduce-fanout-parent-stall. |
