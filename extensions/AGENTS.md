# extensions/ — per-file record

Extension source for `@blackbelt-technology/pi-dashboard-subagents`. pi loads
the default export of `index.ts`. Foreground subagent spawning, plus background spawning when `allowBackground` is on (per-subagent stop via inbound `subagents:stop`); per-event
timeline streamed to the dashboard bridge via `pi.events.emit("subagents:*")`.

| File | Purpose |
|---|---|
| `agent.ts` | `Agent` tool + spawn loop: in-memory child sessions, semaphore lanes, stop control, background spawn, idle keep-alive loop, `ask_parent`, per-child cwd + trust, activation (registers `Agent` + `AgentControl`). → see `agent.ts.AGENTS.md` |
| `events.ts` | Emission layer + timeline types + parent-context inheritance. Wire types `AgentDetails`, `SubagentTimelineEntry`, `AgentStatus`, `TokenUsage`. `AgentDetails.agentMdSource` is `"project"\|"user"\|"bundled"\|"package"`; `agentMdPkg?` carries the originating package `source` string when `source === "package"`. `buildDetails(snapshot)` builds an `AgentDetails` from running state. `emitSubagent{Created,Started,Progress,Completed,Failed}` fire `pi.events.emit("subagents:*")` (bridge renames to `subagent_*`). `emitSubagentProgress` OMITS `entries` key (thin tick). `emitSubagentEntry` fires `subagents:entry` `SubagentEntryEvent { v:1, agentId, toolCallId, index, entry }`. `buildDetails` sets `entryCount = entries.length`. `mapSessionEventToEntry` maps `_end`-flavored session events to entries (idempotent). `createToolCallTracker` pairs `tool_execution_start`→`end` to backfill input. `LiveTail` type + `CLEARED_LIVE_TAIL` sentinel; `buildDetails` always sets `liveTail` (defaults to sentinel). `buildInheritedContext(ctx, opts)` + `compressParentContext` produce the `<parent-context>` prefix (verbatim compaction, no LLM). `SubagentDeltaEvent { v:1, agentId, toolCallId, blockId, kind, offset, text, final }` + `emitSubagentDelta` fire `subagents:delta`; `SubagentEntryEvent.blockId?` links streamed-block steps. See change: scaffold-foreground-subagent-extension, add-agent-md-frontmatter-and-bundled-explore, add-package-agent-discovery-tier, fix-stale-pi-handle-on-reactivation, stream-subagent-entries-per-step, emit-subagent-block-deltas, harden-subagent-lifecycle. `AgentDetails.entriesOmitted?` set only on bounded tool result. Optional `stoppable`/`stopReason`/`queuePosition`/`activeSlots`/`maxConcurrent`/`slotGrantedAt`; `buildDetails` omits each key when unset. See change: manage-subagent-spawn-queue. `AgentDetails.background?: boolean` (set on every snapshot) and `stoppedBy?: "tool" | "event" | "timeout" | "shutdown"`; `buildDetails` passes both through only when set. See change: add-background-subagents. Retries (change: surface-subagent-retries): `SubagentTimelineEntry` kind `"retry"` `{ attempt, maxAttempts, delayMs, text, ts }`; `retryEntryFromEvent(event)` maps pi's `auto_retry_start` (defensive defaults: numbers → 0, empty message → `"Unknown error"`), `null` otherwise; `formatRetryDelay(ms)` (`4s`, `2m 30s`, `1h 5m`; sub-second → `1s`); `AgentDetails.retries?` passed through `buildDetails` only when > 0. `SubagentRetryEvent` (`phase: "scheduled"` with attempt/maxAttempts/delayMs/error, or `"ended"` with attempt/success/finalError?; both with `v`, `agentId`, `toolCallId`, running `retries`) and `emitSubagentRetry` on `subagents:retry`, unthrottled. `AgentDetails.cwd?` + `buildDetails` `cwd` passthrough. See change: add-subagent-orchestration. |
