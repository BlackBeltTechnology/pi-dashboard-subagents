# orchestration.ts — per-file record (sidecar)

Promoted from `extensions/AGENTS.md` (row exceeded the size threshold). Pull-only; search-indexed.

Per-activation `createOrchestrator`: idle pool (TTL, `maxIdle` cap oldest-first, `continueRun`, `dispose`, `disposeAll`); mailbox (`question`/`outcome`, `MAILBOX_MAX` 100 drops oldest outcome never question, summary ≤500); `wait` (one at a time, 250 ms coalesce, default 300 s); push (1 s batch → `sendMessage(customType subagents:mail, {deliverAs followUp, triggerTurn true})`, none while waiting / `notifyParent` off / after `shutdown`); asks (`q<n>`, no timeout, `reply`, `cancelAsks`); `steer` over live sessions; `render` (BLOCKED full form + batch hint); `askLine`; `persistRun` → `appendEntry("subagents:run")`. Emits every orchestration event, ids only. See change: add-subagent-orchestration. Mailbox is now a registry view: `pending()` = unread results + undelivered questions (seq per entry key), `consume(entries, via)` = one read point (markRead + `result_read`, `asking.deliveredAt`); `MAILBOX_MAX`/overflow/`mail_dropped` removed. `wait({ids?, until?, timeoutMs?, signal?})` → `{entries, records, misses, timedOut, interrupted, nothingToWait}`; returns at once when nothing live/pending, ids miss, or a covered child asks; re-checks on registry changes; `MAX_WAIT_MS` 600 s. `render` outcome lines show `· N turns · T tokens`. See change: agent-control-unified-wait.
