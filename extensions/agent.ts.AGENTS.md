Default export `activate(pi)` registers the `Agent` tool and a `resources_discover` handler. `resolveAgentMdPath(type, cwd, bundledDir?, packageIndex?)` resolves `.md` across FOUR tiers, first match wins: project → user → bundled → package; returns `{ path, source, pkg? }`; path-traversal guard (`/`, `\`, `..`) short-circuits first. Tier 4 = package discovery: `buildPackageAgentIndex(cwd, agentDir)` scans installed pi packages' `agents/*.md`. USER-SCOPE ONLY — project-scoped packages never indexed (deliberate conservative default, NOT an SDK limit; SDK does expose `ExtensionContext.isProjectTrusted()`/`SettingsManagerCreateOptions.projectTrusted`). De-dupes by `source`, skips `filtered`, sorts ascending by `source` for deterministic collision winner + stderr warn; NEVER throws (empty index on any failure). Spawn cost is bounded three ways (change: reduce-fanout-parent-stall): `createChildLoader(cwd)` builds a fresh lean `DefaultResourceLoader({cwd, agentDir, noSkills, noPromptTemplates, noThemes})` per child and passes it as `resourceLoader` — NEVER share a loader (one mutable `runtime` per loader; `bindCore` overwrites it, first `dispose()` poisons siblings); `createProgressEmitter(sink, windowMs)` takes a SINK plus a LAZY `schedule(() => details)` so coalesced events never call `buildDetails`, fanning one throttled stream out to `emitSubagentProgress` + `onUpdate`, with `pushTerminalUpdate` delivering terminal status synchronously; module-level FIFO semaphore (`acquireSpawnSlot`/`dispatchSpawnWaiters`, limit `getMaxConcurrent()`, `0` = unlimited) acquired AFTER `emitSubagentCreated` (card shows `queued`) and BEFORE loader/session, released in `finally`; abort while queued rejects with `SpawnAbortedError` → `aborted` result, no session, slot never consumed. `pi` handle bound PER-ACTIVATION via lexical closure: `activate(pi)` passes its own `pi` into `makeAgentTool(pi, exposeIsolated)`; module-level `pi` is FORBIDDEN — nested subagent sessions re-activate this same module instance and clobber the parent's handle, which their `dispose()` then invalidates (stale-ctx on 2nd `Agent` call). Child session: `createAgentSession({ modelRuntime, model, thinkingLevel })`. Model precedence: tool-call `model` > frontmatter `model:` > parent live `ctx.model` > SDK default (settings `defaultModel`); `model` key omitted when none. `getParentModelRuntime(ctx)` reads private `ctx.modelRegistry.runtime` (no public accessor), warns once + returns undefined when missing. ## add-subagent-orchestration

- `Agent` schema gains optional `cwd`; `execute` resolves it first via `resolveSubagentCwd(ctx.cwd, raw.cwd, getCwdScope())`, before `before_spawn`, record, event or slot. Rejection → error result, `CwdRejectDetails {rejected, reason, background}`.
- Child trust (D3): `SettingsManager.create(cwd, agentDir, { projectTrusted: resolveChildProjectTrust(cwd, agentDir) })` passed to BOTH `createChildLoader(cwd, settingsManager)` and `createAgentSession`. Never prompts. Fixes latent bypass (pi defaulted `projectTrusted: true`).
- Package-agent index: per-cwd LRU (`PACKAGE_INDEX_CACHE_MAX` 8); `refreshPackageAgentIndex` clears all; `ensurePackageAgentIndex` builds missing cwd only.
- `runAgentTool` loop (D5): background + `runOpts.keepAlive()` → after a non-stopped run, `parkIdle` releases slot, clears run timer, `phase = "idle"`, hands `IdleHandle {continueWith, dispose}` to `runOpts.onIdle`. `continueWith` acquires a background slot synchronously (`queued`/`started`), next `session.prompt(message)` on same history; `startedAt` + run timer reset per run. `requestStop` in idle → `idleHandle.dispose("cancel"|"shutdown")`, last result stands. Session disposed only when the loop exits.
- `ask_parent` (D9/D12): `makeAskParentTool()` inside `runAgentTool` when `runOpts.ask` set (background only), passed as `customTools`; kept active despite a frontmatter `tools:` allowlist. Releases slot while waiting (no timeout), `untilAborted(answer, [ctrl.signal, toolSignal])`, re-acquires on lane `"resume"`; `runOpts.onSlot` reports `released|reacquire_queued|reacquired`. Any stop → `pending.cancel()`.
- Lanes: `SpawnLane = "foreground" | "resume" | "background"`; `enqueueWaiter` orders foreground → resume → background.
- `runOpts.onSession(LiveSession)` exposes `steer`/`followUp` of the running child.
- `AgentPhase` gains `"idle"`. `AgentControlRegistry.has(agentId)`.
- Activation registers `Agent` + ONE `AgentControl` (`makeAgentControlTool`, D0); `SUBAGENT_MANAGEMENT_TOOLS = [Agent, AgentControl]`. Creates `createOrchestrator(...)` per activation; shutdown: `orchestrator.shutdown()` → stop outstanding → `disposeAll("shutdown")`.
- Exports: `ASK_PARENT_TOOL_NAME`, `CwdRejectDetails`, `DisposeReason`, `IdleHandle`, `LiveSession`.

See change: add-subagent-orchestration.
